## ۱. مقدمه

این سند مشخصات تفصیلی ۲۵ Use Case اصلی سیستم رستوران‌یار را تعریف می‌کند. برای هر Use Case، Actor، پیش‌شرط، جریان اصلی، جریان جایگزین، جریان استثنا و پس‌شرط مشخص شده است.

## ۲. UC-01: مشاهدهٔ منو

| بخش | توضیح |
|------|-------|
| **شناسه** | UC-01 |
| **نام** | مشاهدهٔ منو |
| **Actor اصلی** | مشتری |
| **Actor فرعی** | دیتابیس |
| **Precondition** | کاربر وارد صفحهٔ منو شده باشد |
| **Main Flow** | ۱. مشتری وارد صفحهٔ منو می‌شود<br>۲. سیستم لیست غذاهای موجود را از دیتابیس می‌خواند<br>۳. سیستم منو را با دسته‌بندی نمایش می‌دهد<br>۴. مشتری می‌تواند بین دسته‌ها جابه‌جا شود |
| **Alternative** | اگر منو خالی باشد → پیام: «در حال حاضر منویی موجود نیست»<br>اگر اتصال قطع باشد → نمایش نسخهٔ ذخیره‌شدهٔ محلی |
| **Exception** | اگر دیتابیس خطا دهد → پیام: «خطا در دریافت منو» + Retry |
| **Postcondition** | منو با دسته‌بندی به مشتری نمایش داده شد |
| **Endpoint** | `GET /api/menu` |

## ۳. UC-02: ثبت سفارش با QR

| بخش | توضیح |
|------|-------|
| **شناسه** | UC-02 |
| **نام** | ثبت سفارش با QR |
| **Actor اصلی** | مشتری |
| **Actor فرعی** | سیستم، دیتابیس، KDS |
| **Precondition** | مشتری QR روی میز را اسکن کرده باشد<br>حداقل یک آیتم در سبد باشد |
| **Main Flow** | ۱. مشتری روی «تأیید سفارش» کلیک می‌کند<br>۲. سیستم درخواست را با Pydantic اعتبارسنجی می‌کند<br>۳. سیستم موجودی مواد اولیه را چک می‌کند<br>۴. سیستم تراکنش را شروع می‌کند<br>۵. سیستم سفارش را در orders ثبت می‌کند<br>۶. سیستم اقلام را در order_items ثبت می‌کند<br>۷. سیستم موجودی ingredients را کاهش می‌دهد<br>۸. سیستم تراکنش را Commit می‌کند<br>۹. سیستم با Socket.io به KDS اعلان می‌فرستد<br>۱۰. سیستم شمارهٔ پیگیری برمی‌گرداند<br>۱۱. Frontend پیام موفقیت و شمارهٔ سفارش را نمایش می‌دهد |
| **Alternative** | اگر مشتری آیتمی را حذف کند → مبلغ مجدداً محاسبه می‌شود<br>اگر میز سفارش فعال داشته باشد → هشدار نمایش داده می‌شود |
| **Exception** | اگر موجودی کافی نباشد → پیام: «این غذا موجود نیست» (کد ۴۰۰)<br>اگر سفارش تکراری باشد → پیام: «این سفارش قبلاً ثبت شده» (کد ۴۰۹)<br>اگر خطای دیتابیس رخ دهد → Rollback + پیام خطا (کد ۵۰۰)<br>اگر اتصال قطع شود → ذخیره در localStorage + همگام‌سازی |
| **Postcondition** | سفارش ثبت شد، موجودی کاهش یافت، KDS به‌روزرسانی شد |
| **Endpoint** | `POST /api/orders` |
